# Фактические проверки

Дата: 13 ноября 2026, Москва. Этот документ разделяет выполненные проверки и ещё не подтверждённые условия.

## Выполнено

- **40 автотестов прошли на настоящей PostgreSQL 18.6, Windows, Python 3.12.10.** S3 в этой серии изолирован через moto, а FFmpeg запускается по-настоящему. Проверены аккаунты/сессии, CSRF/Origin, запрет role injection, владельцы, приватная выдача и отзыв доступа, поиск/каналы/плейлисты, лайки/комментарии, модерация/аудит, последний admin, бинарные диапазоны, лимиты/неверные файлы, реальная конвертация и восстановление после истечения lease.
- **Три проверки строгой приватности прошли:** moderator/admin требуют owner grant; жалобы не раскрывают приватные metadata без него. Перед исправлением эти тесты воспроизвели нарушение буквального требования ТЗ.
- **Три регрессии гонок сначала воспроизвели ошибку и затем прошли.** Новая загрузка/обработка завершается раньше старой попытки; старая не может изменить актуальные metadata или опубликованные байты/обложку.
- **Real-stack smoke прошёл:** запущены настоящие PostgreSQL + SeaweedFS 4.44 + отдельный Python worker. Через HTTP зарегистрированы пользователи, загружен приватный файл, получены обработанный MP4 и JPEG, проверены Range, разрешение/отзыв доступа, лайк, комментарий и фильтрация плейлиста. После проверки её видео и плейлист удалены.
- **Браузерный Edge end-to-end прошёл:** поиск, регистрация, выбор файла, передача, ожидание worker, воспроизведение с продвижением времени, лайк, комментарий с HTML в виде текста, создание плейлиста, выдача доступа, мобильная ширина 390 px и локальный Swagger. Ошибок JavaScript не зарегистрировано. Нет горизонтального переполнения; навигация проверена после исправления наложения подсказки входа на мобильное меню.
- **Compose проверен официальным standalone Compose 2.35.1:** application и test YAML успешно разобраны с локальной конфигурацией. **Bash syntax** обоих скриптов проверен `bash -n`. Это проверки структуры, а не запуск контейнеров.
- Начальная миграция Alembic реально применена перед наполнением native PostgreSQL. Повторный seed проверен тестом без дубликатов.
- Исходники прошли Python/JavaScript синтаксические проверки. Самостоятельное ревью кода выполнено отдельным read-only агентом; важные замечания исправлены и покрыты воспроизводящими тестами.

Команды и ожидаемое воспроизведение описаны в README. Браузерные скриншоты создаёт scripts/browser_test.py.

## Проверка чистой Ubuntu

Для проверки создана отдельная виртуальная Ubuntu 24.04 на QEMU в рабочей папке. Официальные образы QEMU и Ubuntu проверены по опубликованным SHA-512/SHA-256. QEMU распакован без установки в Windows; системная перезагрузка или замена окружения пользователя не выполнялась.

**На момент этой записи сценарий чистого Docker/Ubuntu ещё выполняется и не заявляется успешным.** Итоговый результат должен быть обновлён после завершения `start.sh`, real-stack smoke, контейнерных тестов и повторного запуска в VM. Нативный Windows-тест и разбор YAML не заменяют эту проверку.

## Комплект диалогов

Нативный журнал существует. Он содержит внедрённый платформой контекст других проектов/идентификаторы аккаунта. По явной команде пользователя полный оригинал сохраняется отдельным локальным архивом для его проверки. В исходный ZIP он пока не включается. До решения пользователя формальное требование ТЗ о диалогах в общем ZIP остаётся открытым; поддельный или очищенный лог за оригинал не выдаётся.

## Не заявляется

Промышленный аудит безопасности, нагрузочные испытания, многосерверная отказоустойчивость, проверенная процедура аварийного восстановления, HLS/адаптивный bitrate и доставка писем. Автотесты проверяют конкретные сценарии и не являются доказательством отсутствия всех ошибок.
