# YouTube Implementation Plan

> For agentic workers: use superpowers:executing-plans task by task. Preserve the progress ledger and test evidence.

**Goal:** Deliver a working, documented, reproducibly launchable YouTube copy with genuine AI provenance and meaningful Git history.

**Architecture:** Same-origin FastAPI and ES modules; PostgreSQL for metadata and leased jobs; private S3 storage; separate FFmpeg worker; Docker Compose.

**Tech stack:** Python 3.12, FastAPI, SQLAlchemy 2, psycopg 3, boto3, FFmpeg, PostgreSQL 17, S3-compatible object storage.

**Spec:** ../../architecture.md and ../../requirements.txt.

## Global constraints

- Python + FastAPI, PostgreSQL, Swagger at /docs.
- Upload, storage and serving of real video; owner-controlled private access.
- User, moderator and administrator roles; reports and hiding videos.
- Clean Ubuntu startup in one command; README, docs, automated tests and demo seed.
- ZIP includes .git and unsquashed meaningful commits, original AI dialogues and used agent configuration.
- No publication or submission without a separate user instruction.

## Review focus

1. Private videos leaking through ranges, thumbnails, search, channels or playlists.
2. Concurrent worker claims, interrupted processing and upload races.
3. Authentication CSRF, unsafe role changes and registration abuse.
4. Malformed video/range data, limits and subprocess resource exhaustion.
5. Empty installations, repeated startup/seed, unavailable dependencies and mobile controls.
